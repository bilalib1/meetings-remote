# GitHub listing copy

Public-facing copy for the GitHub repo page. Keep it non-technical — the
audience is a small-business owner or home user, not a developer.

Naming constraint (Zoom ToU §7.2): the app name is **Meetings Remote**. It must
never lead with "Zoom" — "Meetings Remote for Zoom" is the allowed phrasing.

## Repo description (the one-liner on github.com)

> Turn an Android tablet, a TV, and a camera into a Zoom meeting room — one
> free app, no PC, no sign-in, no monthly fees.

Alternates, if the above is too long:

> Turn any Android tablet into a Zoom meeting room for your TV — no PC needed.

> Meetings Remote for Zoom: a dedicated meeting-room device from a tablet, a
> TV, and a camera. No PC, no sign-in.
